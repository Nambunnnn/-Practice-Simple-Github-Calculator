# Simple Calculator

A desktop calculator built with Python and CustomTkinter. The interface supports
basic arithmetic, parentheses, decimals, and exponentiation.

## Requirements

- Python 3
- Tk support for your Python installation

## Setup and run

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python Calculator.py
```

On Windows, activate the virtual environment with:

```powershell
.venv\Scripts\Activate.ps1
```

## GitHub

This project is already connected to its GitHub remote on the `main` branch.
After reviewing the files, create the first commit and push it with:

```bash
git add .gitignore README.md requirements.txt Calculator.py
git commit -m "Set up calculator project"
git push -u origin main
```
